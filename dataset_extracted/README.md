# SIH 26140 Detailed Online Learning Dataset

This package contains a 10-chapter quantum-computing curriculum structured like an online learning platform.

Each chapter contains:
- overview
- learning objectives
- multiple sections
- a clear explanation for each section
- point-wise learning elements
- key takeaways
- practice types

Files:
- quantum_learning_detailed_10_chapters.json -> application/database content
- quantum_learning_detailed.csv -> spreadsheet/import format
- quantum_learning_detailed.md -> human-readable course content

The exact ten-chapter organization is a curriculum design derived from the official SIH 26140 problem statement. It is not presented as an official SIH chapter list.
